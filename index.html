Sobre mí

De diagnosticar el problema a entregar el sistema

Trabajo directamente con las áreas operativas de una empresa para identificar dónde falla su proceso actual —información volátil, archivos que crecen sin control, reportes lentos, datos no centralizados— y construyo la aplicación que lo reemplaza de forma estable.

Mis proyectos han acompañado a las empresas en su evolución: de Access a escritorio, y de escritorio a web, manteniendo siempre el foco en la continuidad del negocio durante la transición.

Proyectos

Evolución de aplicativos desarrollados

Cada proyecto documenta la herramienta original y la solución que la reemplazó.

Proyecto 01

TRUE-FACT

Se contaba con una aplicación en Access para el manejo de proformas de facturas de agentes que presentaba inconsistencias y problemas de seguridad: información volátil, lentitud al generar reportes, datos no centralizados y un archivo de más de 100 MB. Se desarrolló un sistema de escritorio propio para reemplazarla.

Java Swing MySQL JasperReports
Proyecto 02

Trébol

Con la implementación de la facturación electrónica a nivel nacional y la recepción de facturas físicas, se evidenciaban reprocesos. Se creó un sistema para optimizar los tiempos y el seguimiento a las facturas, hoy en su versión 2.2, y que más adelante evolucionó a una versión web construida en Laravel.

Java Swing MySQL iText Laravel (v2)
Proyecto 03

Cotizaciones Aviomar

El control de cotizaciones se llevaba en Access, y con el tiempo comenzó a presentar inconsistencias y fallas. Se desarrolló primero un aplicativo de escritorio para la creación de cotizaciones, y recientemente se migró a una aplicación web con panel de indicadores.

Java Access → Escritorio → Web
